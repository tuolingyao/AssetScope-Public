# AssetScope 不动产运营工作台 · 使用手册

面向第一次使用的用户。全文按「安装 → 导入 → 查看 → 备份」的顺序写。

---

## 一、安装与启动

1. 解压下载的 zip 到任意目录，例如 `D:\AssetScope`
2. 双击目录里的 **`AssetScope.exe`**
3. 黑窗口会打印启动信息，浏览器自动打开 `http://127.0.0.1:5178`

解压后目录只有一个入口，其余都在 `app/` 里：

```
AssetScope/
├── AssetScope.exe     ← 双击这个
├── 快速开始.txt
└── app/               ← 程序本体（Node 运行时、后端、前端、数据）
```

首次启动会构建演示库，约 5 秒。之后启动是瞬间完成。

**关于那个黑色窗口**：它是服务本体，**关掉窗口就等于停止服务**。
日常使用建议最小化，不要关。

> 如果双击后窗口一闪而过，说明启动失败。两种办法看报错：
> ① 双击 `app` 文件夹里的 `start.bat`（效果相同，报错会停在屏幕上）；
> ② 在该目录按住 `Shift` 点右键 →「在此处打开命令窗口」，输入 `app\start.bat` 回车。
> 把报错内容发给作者即可。

## 三、导入数据

这是系统的核心功能，也是花时间最多的地方。

### 3.1 下载模板

进入 **资产管理 → 模板批量导入**，点「下载导入模板(.xlsx)」。

模板不是只有一行表头，它自带三样东西：

- **四张数据表**：资产（27 列）、土地组件（25 列）、房产组件（22 列）、经营与账务（10 列）
- **一张「填写说明」**：8 条总则，加每个字段的必填性 / 类型 / 单位 / 精度 / 示例 / 填报要求
- **下拉与约束**：枚举列是下拉，数值列限精度与下限，日期列限区间；每个表头都带批注

**表头文字就是系统认列的唯一依据**：改一个字，这一列就认不出（会被明确提示，不会错位写进隔壁字段）。

### 3.2 填报

- 金额一律用「元」，面积一律用「㎡」；不要写「1200万」这种文字金额
- 空着就是空着，不要用 0 代替「没有数据」
- 日期写 `YYYY-MM-DD`
- 一个资产 = 资产表 1 行 + 组件表 N 行，靠第一列编码关联
- 纯土地资产不用填房产表，纯房产资产不用填土地表
- **经营与账务：整表一个年度**，填在右上角 `B1`，一个资产一行。要补多个年度就分多次导入
- 资产表第一列那个编码**只用于关联**，正式编码入库时由系统生成（要保留自己的编号就填到「备注」）

### 3.3 上传

同一个页面拖拽或点「点击上传」。系统立即解析并逐行校验，结果**暂存为待核对批次**——**确认之前不写进正式资产库**。

这一步会直接告诉你：四张表各读了多少行、有几列表头没认出来、经营表读了几行并命中几个资产、这一批记的是哪个年度。

**表头大面积对不上、缺「资产」表、经营行的编码挂不上资产** —— 这些会当场整份拒绝，并说明原因和行号，而不是「导入成功 0 行」。

### 3.4 核对

点「进入核对页」，逐行看问题项。

| 类型 | 含义 | 能不能入库 |
|---|---|---|
| **阻断**（红） | 硬错误：区划矛盾、必填为空、日期不合法 | 不能，必须先改 |
| **提示**（黄） | 可疑但可接受：面积与权证不符、地址疑似重复 | 能，建议逐条看 |

问题精确到**行号和字段**。可以直接在核对页改，也可以回 Excel 改完重传。

常见的阻断原因：

- **区划为空或写成了占位符**：`/`、`—`、`N/A`、`***` 都会被视为未填
- **区划矛盾**：省市对不上，例如「浙江省长沙市」
- **数值列写了文字**：例如面积列写「待核实」
- **日期无法识别**：例如「去年年底」

### 3.5 入库

阻断消除后点「确认入库」。可以选「整批入库」，也可以只把没问题的部分先入、问题行整组留下改完再入。

入库是**一个事务**：要么全成功，要么全不写入，不会出现「一半资产进了库」。

**年度以表内 `B1` 为准**：如果和界面上填的不一致，系统按表内的来，并把差异提示给你——不会在后台悄悄选一个。

### 3.6 回滚

入库后发现不对，在批次列表点「回滚」。

回滚会撤回这一批创建的资产，但**不会影响你手工新建的数据**。
前提是该批次的数据没有被租赁合同等下游记录引用——有引用时会拒绝回滚，并提示是哪些。

## 四、查看与编辑资产

- **列表页**：支持按区域、业态、使用状态筛选，支持关键字搜索
- **详情页**：分 10 个页签——基本信息、资产组成、权证信息、使用情况、价值信息、
  空间数据、电子档案、收益分析、租赁信息、其他
- **编辑**：详情页右上角「编辑」。组件级信息（土地、房屋各自的面积权证）在「资产组成」页签里改

几个容易困惑的地方：

**为什么有的字段显示「—」？**
「—」表示**不适用**，不是 0。例如纯土地资产没有建筑面积，这里就是「—」。
系统严格区分「没这项」和「这项是 0」——混在一起会让所有平均值失真。

**为什么同类型面积能加，不同类型不能加？**
土地面积和建筑面积是两回事，加起来没有意义。列表里分别给「土地面积」「建筑面积」，
不提供「总面积」。

**为什么删不掉某个资产？**
有未解除租赁合同的资产不允许删除。先处理合同，再删资产。

## 五、预警

预警中心会按 7 类规则自动扫描：

| 规则 | 触发条件 |
|---|---|
| 权证到期 | 权证有效期在阈值内到期或已过期 |
| 抵押到期 | 抵押登记即将到期 |
| 租赁到期 | 合同租期即将结束 |
| 空置 | 有房产但当前无有效租赁 |
| 欠租 | 存在逾期未收账期 |
| 低租金 | 单价低于设定的下限 |
| 指标偏差 | 实际指标偏离目标超过阈值 |

阈值在 **系统管理 → 系统参数** 里调整，改完立即生效。

**预警会去重**：同一个资产同一条规则只保留一条，重复扫描只更新内容和时间，不会堆出一堆重复项。

## 六、数据备份与恢复

**这是最重要的日常操作。**

数据全部在 `app/backend/data/` 目录里。备份步骤：

1. 关掉黑窗口（停止服务）
2. 复制整个 `app/backend/data/` 目录到安全位置
3. 重新双击 `AssetScope.exe`

> ⚠️ 数据库使用 WAL 模式，目录里会同时有 `assetscope.db`、`assetscope.db-wal`、`assetscope.db-shm` 三个文件。
> **必须三个一起复制**，只拷 `assetscope.db` 会丢失最近的写入。

恢复：停止服务 → 用备份的 `data` 目录整体替换 → 启动。

建议把备份做成习惯：每周一次，改大批数据前再做一次。

## 七、升级

1. 备份 `app/backend/data/`
2. 解压新版本到**新目录**
3. 把旧目录的 `app/backend/data/` 整个复制到新目录
4. 启动新目录的 `AssetScope.exe`

**不要直接覆盖旧目录**——新版本可能包含你不再需要的旧程序文件。

## 八、常见报错

| 现象 | 原因与处理 |
|---|---|
| 双击 AssetScope.exe 窗口一闪而过 | 路径含特殊字符，或文件不全。换到 `D:\AssetScope` 这类纯英文路径；也可直接双击 `app\start.bat` 看报错 |
| 黑窗口报「端口已被其他程序占用」 | 程序**不会**去动那个占用者。关掉它，或用下面的方法换端口 |
| 浏览器打开是空白页 | 程序会等服务就绪后才开浏览器，正常不会出现。若仍出现，看黑窗口的报错 |
| 黑窗口报 `EADDRINUSE` | 端口被占用且不是本程序，换端口启动 |
| 导入时提示「表头识别失败」 | 表头行特征不明显。可在 Excel 里把表头单独放一行、去掉合并 |
| 地图页签空白 | 内网无法访问天地图，属正常现象，不影响其他功能 |
| 数据看起来是上个月的 | 确认打开的是正确的 `data` 目录；或检查是否误用了备份 |

### 换一个端口

在同一个黑窗口里先执行（或写到 `.bat` 前面）：

```
set ASSETSCOPE_PORT=5180
"D:\AssetScope\AssetScope.exe"
```

地址随之变成 `http://127.0.0.1:5180`。两套系统装在同一台机器上时各用一个端口即可，
程序之间不会互相干扰。

## 九、反馈

遇到问题时，请提供：

1. 你的表长什么样（脱敏发几行，或说明表头在第几行、有几个合并单元格）
2. 卡在哪一步（上传 / 字段核对 / 校验 / 入库）
3. 报错截图或黑窗口里的错误信息

只要说明这三点，大多数问题不用看数据也能定位。
